Работа на контрольную неделю: доска объявлений о жилье

Задание

Создайте одностраничное приложение на Vue для просмотра объявлений об аренде жилья.

Попробуйте написать парсер, который извлекает данные с какого-нибудь сайта с квартирами (Авито, Циан, Домклик и т.д.) и формирует список объявлений для приложения. При создании парсера можно использовать нейросеть. Полученный код необходимо проверить и быть готовым объяснить его работу.

В объявлении должны отображаться название, цена, район, количество комнат, площадь, описание, а также фотографии. Если какое-то поле отсутствует, приложение должно продолжать работать и показывать доступную информацию.

Реализуйте следующие возможности:

- поиск объявлений по названию;
- фильтрацию по цене, количеству комнат и району;
- отображение количества найденных объявлений;
- добавление объявлений в избранное и просмотр избранного;
- просмотр подробной информации об объявлении.

Если по выбранным условиям объявления не найдены, покажите пользователю соответствующее сообщение.
